# 🌊 DiveDaddy.com

> Professional Divemaster. Ocean Legend. Certified Fish Whisperer.

DiveDaddy.com is a humorous, single-page parody website inspired by a real PADI Divemaster whose clients affectionately nicknamed him **"Dive Daddy."**

This project is intended as a lighthearted tribute to scuba diving culture, dive professionals, marine life, and the universal truth that every dive boat eventually accumulates an alarming number of dad jokes.

---

## Features

* Responsive mobile-friendly design
* Vanilla HTML, CSS, and JavaScript
* Tour reservation form
* Interactive events calendar
* Fake customer reviews
* Dive-themed humor
* Custom Dive Daddy branding and logo
* Zero frameworks
* Easy deployment to GitHub Pages, Netlify, Cloudflare Pages, or Vercel

## Local Development

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/dive-daddy.git
```

Open the project:

```bash
cd dive-daddy
```

Launch `index.html` in your browser.

No build process is required.

No dependencies are required.

No package manager is required.

No scuba certification is required.

---

## Deployment

### GitHub Pages

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Select:

   * Source: Deploy from branch
   * Branch: main
4. Save.

Your site will be published automatically.
